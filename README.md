# FactCheck AI

### Automated Evaluation of Generative AI Models for Fact-Checking and Hallucination Detection

FactCheck AI is a research project investigating the factuality of responses generated by large language models (LLMs) and identifying characteristics associated with hallucinated responses.

The project uses the **TruthfulQA** benchmark to evaluate responses generated by multiple LLMs and develops machine learning models to predict whether a response is hallucinated.

---

##  Research Motivation

Large language models can generate fluent and plausible responses that are factually incorrect. Detecting such hallucinations is important for reliable AI systems, particularly in fact-checking and knowledge-intensive applications.

This project explores two main questions:

1. **How do different language models perform on factual questions across different categories and question types?**
2. **Can question-level and response-level characteristics be used to predict whether an LLM response is hallucinated?**

##  Dataset

The project is based on the **TruthfulQA** benchmark, a benchmark designed to evaluate whether language models generate truthful answers rather than reproducing common misconceptions.

For each question, responses were generated using three LLMs:

* **GPT-4.1-mini**
* **Llama 3.3**
* **DeepSeek**

After preprocessing and filtering, the final dataset contained:

* **806 response samples**
* **18 initial features**
* Multiple question categories and question types
* Both adversarial and non-adversarial questions

The classification task uses a binary hallucination label:

* `0` — Non-Hallucinated
* `1` — Hallucinated

---

##  Response Evaluation

Generated responses were evaluated using multiple NLP metrics:

* **Semantic Similarity**
* **BERTScore**
* **BLEU**
* **ROUGE-1**
* **ROUGE-L**

These metrics were used during response evaluation and manual inspection to help construct the hallucination labels.

> **Important:** These evaluation metrics were **not used as input features for the final ML models**, helping avoid target leakage.

---

##  Machine Learning Methodology

The final dataset was preprocessed by encoding categorical variables and standardizing numerical features.

### Final Feature Set

| Feature              | Description                             |
| -------------------- | --------------------------------------- |
| `Category`           | TruthfulQA question category            |
| `Type`               | Question type                           |
| `Model`              | LLM that generated the response         |
| `ResponseLength`     | Length of the response                  |
| `QuestionLength`     | Length of the question                  |
| `ResponseCharacters` | Number of characters in the response    |
| `AverageWordLength`  | Average length of words in the response |

Three classification algorithms were evaluated:

* **Logistic Regression**
* **Decision Tree**
* **Random Forest**

---

##  Results

The **Random Forest** model achieved the strongest overall performance.

| Model               |   Accuracy |  Precision |     Recall |   F1 Score |    ROC-AUC |
| ------------------- | ---------: | ---------: | ---------: | ---------: | ---------: |
| Logistic Regression |     68.52% |     67.29% |     81.82% |     73.85% |     0.7076 |
| Decision Tree       |     80.86% |     79.38% |     87.50% |     83.24% |     0.9208 |
| **Random Forest**   | **85.19%** | **84.04%** | **89.77%** | **86.81%** | **0.9208** |

The results indicate that question-level and response-level characteristics contain useful signals for distinguishing hallucinated and non-hallucinated responses.

However, these results should not be interpreted as demonstrating that surface-level features alone can reliably detect factual errors.

More robust hallucination detection would require:

* Claim-level verification
* External evidence
* Evaluation across larger and more diverse datasets

---

##  Feature Importance

Feature-importance analysis of the Random Forest model showed the following ranking:

| Rank | Feature                |
| ---: | ---------------------- |
|    1 | **Category**           |
|    2 | **ResponseCharacters** |
|    3 | **QuestionLength**     |
|    4 | **AverageWordLength**  |
|    5 | **ResponseLength**     |
|    6 | **Model**              |
|    7 | **Type**               |

The strong contribution of **question category** suggests that hallucination behavior may vary across different types of factual questions.

> Feature importance represents **predictive importance**, not causal influence.

---

##  Key Findings

### 1. Hallucination Prediction Is Feasible

The Random Forest model achieved:

* **85.19% accuracy**
* **84.04% precision**
* **89.77% recall**
* **86.81% F1 score**
* **0.9208 ROC-AUC**

These results indicate that measurable question and response characteristics can provide useful signals for hallucination prediction.

---

### 2. Question Category Is an Important Signal

Question category was the most influential feature in the Random Forest model.

This suggests that the nature of the factual question can affect hallucination behavior.

---

### 3. Model Identity Is Not the Only Factor

Although the generating model contributed to prediction, several question and response characteristics were more influential.

This suggests that hallucination behavior cannot be explained solely by which LLM generated the response.

---

### 4. Automated Metrics Have Limitations

Semantic similarity and lexical-overlap metrics provide useful evaluation signals, but factual correctness is more nuanced than similarity to a reference answer.

This motivates future work involving:

* Claim-level factual verification
* External evidence retrieval
* Human factuality judgments

---

##  Limitations

This project has some limitations:

* The dataset is based on **TruthfulQA**, which limits generalization to other domains and benchmarks.
* Hallucination labels depend partly on automated evaluation and manual inspection.
* The final feature set primarily captures question and response characteristics rather than factual knowledge.
* The project does not perform comprehensive external fact verification for every individual claim.
* The dataset size is relatively small for developing a general-purpose hallucination detector.
* Random Forest feature importance represents predictive importance and should not be interpreted as causal influence.
* Results may not generalize to unseen LLMs, domains, or datasets without further validation.

---

##  Future Research Directions

Potential extensions include:

### Claim-Level Hallucination Detection

Move from response-level binary classification toward detecting hallucinations at the individual **claim level**.

### Retrieval-Augmented Verification

Use external evidence and retrieval systems to verify factual claims against trusted sources.

### Larger Model Evaluation

Evaluate additional LLMs and newer model families to investigate whether the observed patterns generalize across models.

### Cross-Benchmark Evaluation

Test the approach across multiple factuality benchmarks rather than relying only on TruthfulQA.

### Uncertainty and Abstention

Investigate whether models can recognize uncertainty and appropriately abstain when they lack sufficient evidence.

### Human Evaluation

Compare automated evaluation metrics with human factuality judgments.

### Interpretability

Develop more interpretable hallucination-detection models to better understand why particular responses are classified as hallucinated.

### Cross-Domain Generalization

Study whether hallucination detection generalizes across:

* Domains
* Models
* Question categories
* Question types

##  Research Contribution

FactCheck AI explores whether relatively simple, measurable characteristics of questions and LLM-generated responses can provide useful signals for hallucination prediction.

Rather than treating hallucination detection as a solved problem, the project investigates:

* How hallucination patterns vary across question categories
* Whether response characteristics contain predictive information
* How different classical ML approaches perform
* The limitations of automated factuality metrics
* Directions toward more robust evidence-based hallucination detection

The results provide an initial experimental framework that can be extended toward **claim-level verification, retrieval-augmented fact checking, and cross-model factuality evaluation**.
